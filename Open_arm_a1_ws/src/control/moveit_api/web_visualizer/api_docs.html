⚡ Health & Telemetry
GET /health
JSON or HTML

System health check endpoint used by GitLab CI, watchdog timer, and human operators. Returns status, ros_ok, and active_build.

curl -s http://192.168.1.226:5050/health
GET /api/status
Telemetry

Query live robot joint positions, arm motion state (is_moving), and joint state streaming availability.

curl -s http://192.168.1.226:5050/api/status
GET /api/pose/<group_name>
group_name: left_arm | right_arm

Calculates and returns the current Cartesian 6D pose (position {x,y,z} and quaternion {x,y,z,w}) of the arm end-effector.

curl -s http://192.168.1.226:5050/api/pose/right_arm
🦾 Robot Motion & Trajectory
POST /api/move/joints
Trajectory

Plans and executes a synchronized joint-space motion for the specified planning group.

curl -X POST http://192.168.1.226:5050/api/move/joints -H "Content-Type: application/json" -d '{"group":"right_arm","positions":[0,0,0,0,0,0,0],"unit":"rad"}'
POST /api/move/pose
Cartesian

Move the end-effector to a target 3D Cartesian position and orientation quaternion via inverse kinematics.

curl -X POST http://192.168.1.226:5050/api/move/pose -H "Content-Type: application/json" -d '{"group":"right_arm","position":{"x":0.3,"y":-0.2,"z":0.4},"orientation":{"x":0,"y":0,"z":0,"w":1}}'
POST /api/stop
Safety

Emergency stop / motion abort. Immediately stops active trajectory execution on all planning groups.

curl -X POST http://192.168.1.226:5050/api/stop
🔄 State Machine & Sequences
GET /api/fsm/state
FSM

Query the current supervisory FSM state (BOOTING, IDLE, RUNNING, PAUSED, FAULT) and active step index.

curl -s http://192.168.1.226:5050/api/fsm/state
POST /api/fsm/trigger
Command

Send transition events to the sequence executor FSM (e.g. pause, resume, abort, reset).

curl -X POST http://192.168.1.226:5050/api/fsm/trigger -H "Content-Type: application/json" -d '{"event":"pause"}'
GET /api/sequences
Store

List all pre-recorded choreography sequences loaded in the robot's YAML sequence store.

curl -s http://192.168.1.226:5050/api/sequences
✋ Grippers & End-Effectors
POST /api/gripper
openarm_hand

Control parallel-jaw gripper on either arm. Accepts {"side": "left"|"right", "action": "open"|"close"}.

curl -X POST http://192.168.1.226:5050/api/gripper -H "Content-Type: application/json" -d '{"side":"right","action":"open"}'
POST /api/hand
amazing_hand

Multi-DOF dexterous hand command. Supports predefined gestures or per-finger joint vector positions.

curl -X POST http://192.168.1.226:5050/api/hand -H "Content-Type: application/json" -d '{"side":"right","action":"open"}'
📜 Supervisor Logs API
GET /api/logs
Query

Query historical supervisor error logs. Supports parameters: since (ISO timestamp), limit (max 1000), level (ERROR / FATAL), node (substring filter).

curl -s "http://192.168.1.226:5050/api/logs?level=ERROR&limit=10"
GET /api/logs/files
Files

List available daily JSONL supervisor log archives with dates and file sizes on disk.

curl -s http://192.168.1.226:5050/api/logs/files
